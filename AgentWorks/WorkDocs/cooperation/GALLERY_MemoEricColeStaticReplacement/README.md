# Memo Eric Cole Static Replacement

## Summary
- `/memo`의 기존 메모 데이터·편집 흐름을 제거하고 Eric Cole 템플릿 구조의 영문 포트폴리오로 교체한다.

## Background
- 사용자가 Framer 원본의 영문 내용, 섹션 흐름, 스크롤/글리치 연출, TV 푸터를 요청했다.

## Scope
- Hero, Intro, Work, Approach, Services, About, Contact, Client Proof/Footer.
- 특수문자→본문 스크램블, 스크롤 글자 채우기, 후기 티커, 소셜 hover 글리치, 서울 시각/요일/연도.
