# R01 AI Review

## Scope
- 편집창 복사 버튼과 작성창 붙여넣기 버튼
- 게시글 복사 payload의 Controller 전달
- 기존 이미지 URL 및 새 File 저장 호환

## Findings
- 복사 데이터는 편집창의 현재 초안에서 생성되어 저장 전 변경도 포함한다.
- 텍스트 레이어 객체와 내용 이미지 메타데이터를 복제하여 후속 편집에서 원본 상태를 변경하지 않는다.
- 기존 카테고리가 삭제된 경우 붙여넣을 때 미분류로 안전하게 처리한다.
- 기존 URL은 재업로드하지 않고 재사용하며 새 파일만 업로드한다.

## Validation
- `npx tsc --noEmit`
- 관련 파일 대상 `npx eslint`
- 대상 파일 `git diff --check`
- 개발 서버 `/gallery` HTTP 200

## Decision
- 승인
