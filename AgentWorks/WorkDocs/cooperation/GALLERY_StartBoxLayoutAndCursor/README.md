# 시작 페이지 박스 배치와 커스텀 커서

## Summary
- 시작 페이지에 포인터 추적 커스텀 커서와 호버 대상 라벨을 추가한다.
- 관리자 설정에서 카테고리별 메인 화면 5×5 드래그 편집으로 박스 배치를 저장한다.
- 박스 등장·퇴장을 참고 GIF처럼 순차 애니메이션으로 표현한다.

## Background
- `Reference/1. 기본페이지/`의 PNG와 GIF를 구현 기준으로 사용한다.
- 기존 시작 페이지는 카테고리별 박스 배치가 CSS에 고정되어 있다.

## Scope
- 시작 페이지 Hero와 Header의 커서 표현 및 호버 라벨
- 시작 페이지 카테고리별 메인 화면 드래그 배치 설정 UI
- Supabase 저장 스키마, 서버 초기 상태, 브라우저 동기화
- 박스 등장·퇴장 애니메이션
