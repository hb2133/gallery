# 기본 페이지 카테고리 설정창 레퍼런스 레이아웃

## Summary
- 기본 페이지 카테고리 설정창을 레퍼런스처럼 상단 카테고리 탭, 좌측 5×5 미리보기, 우측 선택 항목 편집 구조로 변경했다.

## Background
- 기존은 4개 카테고리와 게시판 설정이 세로로 반복돼 한눈에 보기 어려웠다.

## Scope
- 설정 패널 레이아웃을 재구성했다. 이후 `GALLERY_SettingsPreviewBoxDrag` 작업에서 위치 이동을 설정 미리보기 안으로 통합했다.
