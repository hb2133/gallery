# Task

## Context
- 스크롤 보기의 이미지 이동 버튼을 기존 흰색 원형 디자인으로 되돌린다.
- 마우스와 터치 드래그로 이전·다음 이미지를 넘길 수 있게 한다.
- 이미지가 즉시 교체되는 느낌 대신 이동 방향과 다음 이미지가 이어지는 전환을 제공한다.

## Implementation
- 빨강·파랑 이동 버튼 오버라이드를 제거하고 기존 밝은 원형 버튼 스타일을 공통 적용한다.
- 포인터 드래그 방향과 저장된 페이지 진행 방향을 연결한다.
- 드래그 중 현재 이미지와 인접 이미지가 함께 움직이고, 거리·속도 기준을 넘으면 전환을 완료한다.
- 버튼과 키보드 이동도 같은 620ms 슬라이드 전환을 사용한다.
- 스크롤 보기에서 페이지 점 인디케이터를 함께 표시한다.

## Initial Render Harness
- 상세 팝업의 일시적 상호작용 변경이며 저장 기능이 아니므로 적용 대상이 아니다.

## Result
- TypeScript, ESLint, Next.js production build를 통과했다.
- `/gallery`가 `192.168.0.41:3000`에서 HTTP 200을 반환한다.

## Review Follow-up
- 전환 완료 직후 진입 애니메이션 억제를 한 프레임 만에 해제하면서 새 활성 이미지에 진입 애니메이션이 다시 붙어 깜빡이는 현상을 확인했다.
- 드래그 완료 이미지에는 억제 상태를 유지하고, 다음 이동을 시작할 때만 해제하도록 수정했다.
- 완료되지 않은 드래그가 원위치로 복귀할 때도 같은 재진입 애니메이션을 막았다.
