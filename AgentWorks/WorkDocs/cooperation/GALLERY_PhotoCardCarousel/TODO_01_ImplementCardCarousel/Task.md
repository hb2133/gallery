# Task

## Context
- 사진 페이지의 8개 단일 이미지 카드를 4개의 다중 이미지 포토카드로 통합한다.

## Current Understanding
- 기존 구조는 이미지 한 장이 게시글 카드 하나와 1:1로 대응했다.
- 상세 팝업 화살표는 다른 게시글 카드로 이동했다.

## Observed Issues
- 최초 해석에서는 여러 카드 각각에 복수 이미지를 넣었으나 사용자 의도는 게시글 자체를 하나로 통합하는 것이었다.
- 이후 사용자 피드백으로 최종 목표를 게시글 4개, 게시글별 사진 2장으로 구체화했다.

## Decision Notes
- 사진 페이지에는 포토카드 4개를 유지하고 관련 사진 2장씩 각 카드의 이미지 배열로 소유하게 한다.
- 상세 팝업 이동은 카드 간 이동이 아니라 현재 카드의 이미지 인덱스 전환으로 한정한다.

## Implementation Notes
- GalleryIndexItems를 관련 사진 2장씩 가진 4개 항목으로 통합했다.
- 필터 UI와 필터 상태를 제거했다.
- 상세 팝업에 좌우 화살표, 키보드 방향키, 하단 점 선택 기능을 추가했다.
- 상세 팝업의 좌우 화살표는 사진 영역 hover 또는 키보드 focus 안에서만 표시하고, hover가 없는 터치 환경에서는 항상 표시한다.
- 클릭 후 남은 버튼 포커스가 hover 종료 뒤에도 화살표를 유지하지 않도록 컨테이너 `focus-within` 대신 버튼 `focus-visible`만 키보드 표시 조건으로 사용한다.
- 카드 대표 이미지 비율을 1:1로 변경했다.
- 카드 그리드를 데스크톱 3열, 태블릿 2열, 모바일 1열로 구성했다.

## Result
- ESLint와 TypeScript 검사 통과
- `/gallery` HTTP 200 확인
- 포토카드 4개와 각 카드 제목이 렌더링됨을 확인
