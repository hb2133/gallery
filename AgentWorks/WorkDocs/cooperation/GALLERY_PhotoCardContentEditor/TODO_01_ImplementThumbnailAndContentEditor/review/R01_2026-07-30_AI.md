# R01 AI Review

## Scope
- 사진 카드 썸네일 및 내용 이미지 통합 편집
- 내용 이미지 저장 및 초기 상태 병합

## Findings
- 썸네일과 내용 이미지는 한 번에 하나만 열리는 아코디언이다.
- 기존 URL과 새 파일을 함께 저장하며 내용 이미지는 1~20장으로 검증한다.
- 코드 고정 카드도 같은 ID의 저장 행으로 덮어쓰고 목록 중복 없이 병합한다.
- 서버 첫 HTML에 `PhotoPosts.ImageLayout` 저장 좌표가 포함된다.

## Verification
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- `/gallery` server HTML `PhotoPosts`, `ImageLayout`, 저장 좌표 확인

## Decision
- Approved.
