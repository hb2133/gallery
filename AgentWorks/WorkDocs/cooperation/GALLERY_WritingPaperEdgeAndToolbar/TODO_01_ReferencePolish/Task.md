# Task

## Context
- Writing 카드가 완전한 직사각형이고 비호버 상태에서 제목이 노출되며 레퍼런스의 호버 전환과 달랐다.

## Current Understanding
- 고정 다각형 변형을 카드별로 분산하고, 너비와 높이를 같은 곡선으로 전환하면 GIF의 아코디언형 움직임을 재현할 수 있다.

## Observed Issues
- 런타임에서 확인된 현상이나 새로 발견된 문제를 적는다.

## Decision Notes
- 방향이 바뀐 이유와 폐기한 가설을 적는다.

## Initial Render Harness
- 저장 기능 없음. 카드 외곽선과 비호버 상태는 서버/클라이언트에서 동일한 정적 인덱스로 결정한다.

## Implementation Notes
- 카드별 다섯 가지 종이형 `clip-path`를 적용했다.
- 비호버 제목을 제거하고 호버 때만 상세 내용을 표시한다.
- GIF 비율에 맞춰 카드 너비와 높이가 함께 확장되도록 조정했다.
- 기존 Writing DB 카테고리는 무시하고 새 기본 카테고리만 첫 화면에 표시한다.

## Result
- 1440×900 브라우저에서 카드 7개 외곽선, 비호버 상세 opacity 0, 가로 오버플로 없음, 카테고리 우측 배치를 확인했다.

## History Index
- 아직 분리된 이력이 없다.
