# 사진 게시글 페이지 바로가기 토글과 직접 이동

## Summary
- 사진 게시글 1번 스타일의 스크롤 페이지 바로가기에 열기·숨기기 토글과 페이지 번호 직접 이동을 추가한다.

## Background
- 상시 노출 목록은 빠른 탐색에 유용하지만 필요할 때 화면에서 숨길 수 없고, 페이지가 매우 많으면 번호를 직접 찾는 데 시간이 걸린다.

## Scope
- 목록 아래에 직접 페이지 입력과 토글을 배치한다.
- 입력 범위를 실제 페이지 수로 제한하고 기존 직접 이동 함수를 재사용한다.
- 목록을 숨기면 직접 입력 폼도 함께 숨긴다.
