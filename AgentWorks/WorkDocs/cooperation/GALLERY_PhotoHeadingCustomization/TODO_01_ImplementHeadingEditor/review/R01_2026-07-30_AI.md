# R01 AI Review

## Scope
- 사진 게시판 상단 제목과 오른쪽 소개 문구 설정
- 공개 웹폰트 업로드 및 방문자 적용
- 서버 초기 상태와 첫 HTML 일치

## Findings
- 차단 이슈 없음.
- 숫자 입력은 입력 중 자유 편집, blur 시 범위 보정으로 동작한다.
- 저장값은 Supabase에서 서버 렌더링 전에 읽는다.
- 업로드 폰트는 허용 확장자와 10MB 제한을 검사한다.

## Verification
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- production `/gallery` 첫 HTML 확인

## Decision
- Approved.
