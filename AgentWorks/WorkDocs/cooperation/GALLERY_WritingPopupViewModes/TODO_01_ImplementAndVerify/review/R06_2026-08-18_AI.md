# Review R06

Reviewer: AI
Date: 2026-08-18
Result: in_review

## Findings
- 책 페이지 내부 스크롤바를 화살표 없는 5px 둥근 막대와 투명 트랙으로 정리하고 모든 scrollbar 의사 요소에 프로젝트 커서를 적용했다.
- 본문만 별도 스크롤 영역으로 분리해 페이지 번호는 스크롤과 무관하게 책의 좌·우 하단에 고정된다.
- 팝업 기준 상자를 책 `1010×645`와 공간 보기 `680×680`에 맞춰 외부 도구·진행 표시의 불필요한 간격을 제거했다.
- 공간 화살표는 전체 리더가 아니라 정사각형 본문 캔버스를 hover할 때만 표시된다.
- 공간 보기에서 책 보기로 돌아갈 때 작은 중간 폭으로 pageflip이 초기화되지 않도록 팝업 크기 전환을 즉시 확정한다.
- Gallery처럼 책넘김 애니메이션 동안 고정 입력 차단막을 표시해 더블클릭의 연속 넘김을 막았다.
- 페이지 번호의 크기·굵기·자간·그림자와 기본 서체를 Gallery와 맞췄다.
- 상하좌우 보기 캔버스를 Gallery와 같은 최대 680px 정사각형으로 만들고 화살표 좌표의 기준 요소를 통일했다.
- 상하좌우 페이지 전환을 Gallery와 같은 620ms 두 겹 페이드·방향별 3D 흔들림으로 교체했다.
- 네이티브 텍스트 드래그는 막고 Gallery와 같은 8px 시작 거리, 16% 이동 거리·속도 판정으로 상하좌우 드래그 이동을 추가했다.
- 상하좌우 보기의 내용 하단 페이지 번호는 숨기고 외부 진행 표시만 유지했다.
- TypeScript, 전체 ESLint, diff 검사와 방향 전환 체크가 통과했다.

## Decision
- 코드 검사는 승인한다. 기존 개발 서버 재시작 후 실제 표시와 연속 클릭 차단을 확인한다.
