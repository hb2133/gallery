# Task

## Context
- 로그인한 관리자가 사진 카드 썸네일을 시각적으로 편집하고 모든 방문자에게 같은 결과를 보여줘야 한다.

## Current Understanding
- 원본 상세 사진은 유지하고 목록 카드의 썸네일 이미지, 카테고리와 텍스트 레이어만 별도 저장한다.
- 텍스트 레이어는 내용, 폰트, 크기, 색상과 백분율 위치를 가진다.

## Observed Issues
- 카테고리 select의 `Event.currentTarget.value`를 state updater 내부에서 읽어 updater 실행 시점에 `currentTarget`이 `null`이 되는 오류가 발생했다.

## Decision Notes
- 카드 hover 수정 아이콘은 관리자에게만 표시한다.
- 편집 캔버스는 실제 카드와 같은 3:4 비율을 사용한다.
- 텍스트는 캔버스에서 직접 드래그하거나 가로·세로 숫자로 위치를 조정한다.
- 썸네일 파일은 최대 10MB의 JPEG, PNG, WebP, GIF를 지원한다.
- 카드 카테고리 선택지는 관리자 카테고리 설정과 같은 목록을 사용한다.
- 저장된 카테고리가 삭제되면 카드는 `전체`에만 남고 개별 필터에는 포함하지 않는다.

## Implementation Notes
- 카드별 공개 설정 테이블과 공개 썸네일 Storage를 추가했다.
- 관리자 전용 INSERT·UPDATE·업로드 정책을 적용했다.
- 다중 텍스트 레이어 목록과 선택 인스펙터를 구현했다.
- 텍스트 추가·삭제, 폰트·크기·색상·위치 변경과 이미지 교체를 구현했다.
- 현재 카테고리 목록과 연동된 `카테고리 없음` 포함 선택기를 구현했다.
- 카테고리 선택값을 이벤트 핸들러에서 먼저 캡처한 뒤 state updater에 전달한다.

## Result
- 저장된 카드 설정이 공개 조회되어 로그인하지 않은 방문자에게도 적용된다.
- TypeScript, ESLint, 프로덕션 빌드와 `/gallery` HTTP 200 검증이 통과했다.
