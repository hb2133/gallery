# Task

## Context
- 사진 게시판 카테고리를 관리자 로그인 상태에서 직접 추가·삭제해야 한다.

## Current Understanding
- `전체`는 고정하고 나머지 이름 목록만 Supabase에 저장한다.
- 카테고리 삭제는 사진 자체를 삭제하지 않으며 해당 필터만 제거한다.

## Observed Issues
- 초기 구현 직후 원격 마이그레이션 전에는 저장 테이블이 없어 추가·삭제가 실패했다.
- 삭제 아이콘 공간을 오른쪽 padding만으로 확보해 글자가 왼쪽으로 치우쳤다.

## Decision Notes
- 삭제 아이콘은 카테고리 버튼 외곽 우측 상단에 배치하고 본문 padding은 좌우 대칭으로 유지한다.
- 비로그인 사용자는 카테고리 조회·필터만 가능하고 편집 UI는 렌더링하지 않는다.

## Implementation Notes
- 관리자에게만 각 카테고리의 `×`와 맨 오른쪽 `+`를 표시한다.
- 인라인 이름 입력으로 새 카테고리를 생성한다.
- 사진 카드 아래의 기간·카테고리·글귀 영역을 제거했다.
- 공개 SELECT와 관리자 INSERT·UPDATE RLS를 적용했다.

## Result
- 원격 설정에서 기본 카테고리 배열을 공개 조회할 수 있다.
- TypeScript, ESLint, 프로덕션 빌드와 `/gallery` HTTP 200 검증이 통과했다.
