# 영상 작성 편집 제목 우선 및 카테고리 토글

## Summary
- 영상 글쓰기와 편집 폼에서 제목을 첫 입력 항목으로 배치하고 카테고리를 접고 펼칠 수 있는 화살표 드롭다운으로 변경했다.

## Background
- 제목보다 카테고리가 먼저 보여 입력 순서가 어색했고 네이티브 선택창은 펼침 상태 피드백이 부족했다.

## Scope
- 공용 영상 작성/편집 패널의 입력 순서와 카테고리 선택 UI.
