# 짧은글 게시판 Eric Cole 템플릿 전면 교체

## Summary
- `/memo`의 책넘김 화면을 Eric Cole Framer 템플릿 구조의 단일 스크롤 아카이브로 전면 교체한다.

## Background
- 기존 짧은 글 게시판은 목록과 큰 책 UI만 있어 제공된 타이포그래피 중심 레퍼런스와 구조가 달랐다.

## Scope
- 히어로, 선택 글, 기록 방식, 전체 아카이브, 소개, 편집, 하단 조각 섹션.
- 기존 메모 선택, 목록 페이지, 새 메모 추가, 제목·본문 편집 기능 연결.
- 데스크톱과 모바일 반응형 구성.
