# Task

## Context
- 사진 상세의 책 보기를 한 줄 메모처럼 실제 책장을 넘기는 방식으로 변경한다.

## Current Understanding
- 한 줄 메모는 `react-pageflip`과 종이·그림자 스타일을 사용한다.
- 사진 뷰어의 기존 책 보기는 정적인 2열 CSS 레이아웃이다.

## Observed Issues
- 기존 책 보기는 페이지 모서리 드래그와 종이 넘김이 없다.
- 팝업이 사진책에 비해 크게 느껴진다.

## Decision Notes
- 메모에서 검증된 `react-pageflip` 엔진을 재사용한다.
- 별도 표지·설명은 추가하지 않고 각 사진을 한 페이지로 사용한다.
- 데스크톱은 펼친 책, 모바일은 한 페이지 책으로 반응형 처리한다.

## Initial Render Harness
- 게시글을 누른 뒤 생성되는 상호작용 뷰이며 저장 설정을 추가하지 않아 해당 없음.

## Implementation Notes
- 모서리 드래그, 클릭, 좌우 키로 넘기는 포토북을 구현했다.
- 호버만으로 페이지가 접히지 않도록 모서리 미리보기 옵션을 끄고 클릭 드래그는 유지했다.
- 페이지 플립 이벤트를 기존 활성 이미지 인덱스와 동기화했다.
- 종이 여백, 중앙 그림자, 하단 페이지 블록과 페이지별 `현재/전체` 표시를 적용했다.
- 첫 카드에 기존 사진 8종을 활용한 20페이지 테스트 구성을 추가했다.
- 1·2 선택기를 팝업 좌측 상단에 밀착하고 책/스크롤 팝업 크기를 동일하게 맞췄다.
- 포토북 페이지 최대 크기와 무대 여백을 조정해 1번 보기의 실제 콘텐츠 면적도 2번 보기와 맞췄다.
- `flipping` 상태 동안 전체 입력 차단 레이어를 표시해 연속 클릭과 다른 컨트롤 조작을 막았다.
- 입력 차단 중에도 로딩 포인터가 나타나지 않도록 기본 화살표 커서를 유지했다.
- 닫기 `×`를 1·2 선택기의 반대편인 팝업 오른쪽 상단 바깥으로 이동했다.
- 데스크톱 페이지 최대 크기를 505×680으로 높이고 무대 여백을 제거했다.
- 페이지의 흰 종이 배경·안쪽 여백·테두리를 제거하고 이미지를 full-bleed cover 방식으로 적용했다.
- 데스크톱 책 오른쪽 바깥에 정사각형 페이지 책갈피를 세로 배치하고 활성 페이지와 플립 엔진을 동기화했다.
- 책갈피는 `turnToPage` 즉시 전환 대신 `flip` 애니메이션으로 이동한다.
- 20개 책갈피는 10개씩 두 열로 표시한다.
- 활성 페이지를 짝수 시작 인덱스로 정규화해 한 화면에 펼쳐진 두 페이지 책갈피를 동시에 강조한다.
- 별도 hard cover 페이지를 앞에 추가하고 내용 페이지 인덱스와 책 엔진 인덱스를 1칸 보정한다.
- 표지에서는 활성 책갈피를 해제하고, 현재 펼침면의 책갈피를 다시 누르면 표지로 플립한다.
- 표지에는 카드 썸네일과 저장된 텍스트 레이어를 같은 스타일·좌표로 함께 표시한다.
- 포토북 하단의 종이 단면 장식선을 제거했다.
- 스크롤 보기의 처음/끝 경계에서 반대편으로 순환하지 않으며 이동 가능한 화살표만 표시한다.
- 이전·다음 방향에 맞춰 사진이 좌우에서 슬라이드되어 들어오도록 전환 애니메이션을 적용했다.
- 다크 테마 전역 색상 상속을 차단해 이미지 이동 화살표를 짙은 색으로 고정했다.
- 모바일에서는 책갈피를 화면 안쪽 하단 가로 스크롤 목록으로 전환했다.

## Result
- TypeScript, ESLint, Next.js production build 통과.
