# 사진 상세 책 넘김 뷰어

## Summary
- 사진 상세 1번 보기를 한 줄 메모와 같은 실제 페이지 플립 포토북으로 교체했다.
- 첫 번째 사진 게시글에 테스트용 20페이지를 연결했다.
- 호버 접힘 없이 클릭 드래그 중에만 페이지가 따라오며 두 보기의 팝업 크기를 통일했다.
- 포토북 내부 면적도 스크롤 보기와 같은 팝업 크기를 채우도록 확장했다.
- 페이지 넘김 중에는 모든 입력을 차단하고 닫기 아이콘을 1·2 선택기의 반대편인 오른쪽 상단에 배치했다.
- 데스크톱 포토북의 남는 여백을 제거해 2번 보기와 같은 영역을 거의 가득 채우도록 확대했다.
- 흰 종이 아웃라인을 제거하고 사진이 각 책 페이지 전체를 채우도록 변경했다.
- 책 오른쪽 바깥에 페이지별 정사각형 책갈피 바로가기 버튼을 추가했다.
- 책갈피 이동도 페이지 플립 애니메이션을 사용하며 20개는 10개씩 두 열로 표시된다.
- 현재 펼침면의 두 페이지 책갈피를 `1·2`, `3·4` 단위로 함께 강조한다.
- 스크롤 보기의 순환 이동을 제거하고 방향별 사진 슬라이드 전환을 추가했다.
- 다크 모드에서도 이동 화살표가 보이도록 밝은 버튼과 짙은 아이콘 대비를 고정했다.
- 책을 열면 썸네일 표지가 오른쪽 한 면에 먼저 보이고, 넘긴 뒤 내용 1·2페이지가 펼쳐진다.
- 활성 책갈피를 다시 누르면 책 표지로 돌아간다.
- 페이지 목록을 우측 하단 토글형 세로 스크롤 패널로 변경했다.
- 책 이미지는 4:3 사진도 잘리지 않도록 전체가 보이는 `contain` 방식으로 표시한다.

## Background
- 기존 책 보기는 두 이미지를 나란히 배치하고 짧은 CSS 전환만 제공했다.

- 첫 게시글 10개 테스트 이미지.
