# Task

## Context
- 책갈피 1·2로 이동하면 사진은 첫 펼침면으로 이동하지만 활성 책갈피 표시가 갱신되지 않는 경우가 있다.

## Cause
- 활성 표시는 부모 이미지 인덱스만 파생하고, 책갈피 클릭 시에는 플립 엔진의 완료 이벤트만 기다렸다.
- 첫 펼침면 이동에서 완료 이벤트가 늦거나 생략되면 실제 사진과 책갈피 표시가 일시적으로 분리됐다.

## Implementation
- 책갈피 클릭 순간 로컬 펼침면 상태를 대상 쌍으로 동기화한다.
- 실제 `onFlip` 이벤트에서도 펼침면 상태를 다시 확정한다.
- 부모 이미지 인덱스가 외부에서 바뀔 때도 같은 짝수 펼침면 기준으로 동기화한다.
- 포토북 앞에 썸네일 hard cover를 추가해 처음에는 오른쪽 표지만 표시한다.
- 현재 펼침면의 활성 책갈피를 다시 누르면 표지로 이동한다.

## Initial Render Harness
- 상세 팝업의 일시적 상호작용 상태이며 저장 기능이 아니므로 적용 대상이 아니다.
