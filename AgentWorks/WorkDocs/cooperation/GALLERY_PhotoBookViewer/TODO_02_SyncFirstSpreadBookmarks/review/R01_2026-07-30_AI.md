# R01 AI Review

## Scope
- 첫 펼침면 책갈피 동기화
- 썸네일 및 텍스트가 포함된 책 표지
- 활성 책갈피의 표지 복귀

## Findings
- 표지가 책 엔진의 0페이지, 내용은 1페이지부터 매핑된다.
- 표지에서는 책갈피가 비활성이고 첫 장을 넘기면 내용 1·2가 함께 활성화된다.
- 현재 펼침면의 책갈피를 다시 누르면 표지로 플립한다.
- 표지의 썸네일과 텍스트 레이어는 카드 저장값을 사용한다.
- 하단 종이 단면 장식선은 제거됐다.

## Verification
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`

## Decision
- Approved.
