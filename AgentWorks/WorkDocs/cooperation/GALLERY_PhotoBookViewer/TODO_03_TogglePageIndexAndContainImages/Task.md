# Task

## Context
- 책 아래에 모든 페이지 버튼을 항상 표시하면 수백 페이지에서 탐색과 화면 배치가 불리하다.
- 4:3 이미지를 책 페이지에 꽉 채우면서 가장자리가 잘리는 문제를 없앤다.

## Implementation
- 책 우측 하단에 현재 위치가 표시되는 페이지 선택 토글을 추가한다.
- 토글을 열 때만 우측 가장자리에 한 줄 세로 스크롤 페이지 선택 패널을 표시한다.
- 패널을 열면 현재 펼침면이 보이는 위치로 자동 스크롤한다.
- 페이지를 선택하면 패널을 닫고 기존 책 넘김 애니메이션으로 이동한다.
- 책 내용 이미지를 `cover` 대신 `contain`으로 표시해 4:3 사진 전체를 보존한다.

## Initial Render Harness
- 상세 팝업의 일시적 상호작용과 표시 방식 변경이며 저장 기능이 아니므로 적용 대상이 아니다.

## Result
- TypeScript, ESLint, Next.js production build를 통과했다.
- `/gallery`가 `192.168.0.41:3000`에서 HTTP 200을 반환한다.

## Review Follow-up
- 여러 열로 펼쳐지던 페이지 버튼을 한 줄 세로 목록으로 변경해, 우측에서 스크롤로 페이지를 탐색하는 구조를 명확히 했다.
