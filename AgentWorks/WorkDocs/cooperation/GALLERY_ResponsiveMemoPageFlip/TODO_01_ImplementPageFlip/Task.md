# Task

## Context
- 한 줄 메모를 반응형 책 UI에서 실제 페이지를 넘기듯 탐색할 수 있어야 한다.

## Current Understanding
- 기존 Controller는 활성 페이지 인덱스를 즉시 바꾸고 드래그 진행률과 전환 단계를 관리하지 않았다.
- 기존 Book에는 perspective가 있었지만 닫힌 책과 펼친 책의 시점 및 재질 연결이 약했다.

## Observed Issues
- 페이지가 순간적으로 교체되어 책 형태와 상호작용이 연결되지 않았다.

## Decision Notes
- Controller가 넘김 방향, 드래그 진행률, closing/opening lifecycle을 소유한다.
- 종이가 가장 얇게 접히는 시점에 활성 페이지를 교체한다.
- 모션 감소 설정에서는 애니메이션과 대기 없이 즉시 전환한다.
- 페이지는 순환하지 않으며 마지막 페이지에서는 다음 모서리를 제공하지 않는다.
- 첫 페이지의 이전 방향은 책 닫기 동작으로 해석한다.
- 이전 방향의 모서리와 회전 대상은 왼쪽 지면에 두고, 왼쪽 종이가 책등을 축으로 오른쪽을 향해 접히게 한다.
- 전환 목표 페이지를 정착 시점까지 별도 지면으로 유지해 넘기는 종이 뒤가 빈 흰색으로 노출되지 않게 한다.
- Heyzine 프리뷰처럼 이동 지면에 원근, 비대칭 모서리, 접힘 음영과 가변 그림자를 함께 적용한다.
- 닫힌 표지와 펼친 지면은 교체 렌더링하지 않고 같은 Book 안에 유지하며, 표지가 중앙 책등을 축으로 열리게 한다.
- CSS `rotateY` 기반 전환은 제거하고 `react-pageflip`/`StPageFlip`의 포인터 좌표 기반 접힘 계산을 사용한다.
- 표지 역시 soft page로 설정해 PubHTML5처럼 하단 모서리의 작은 컬에서 시작해 드래그 거리만큼 접힌 면이 커지게 한다.
- 각 메모의 recto와 이전 메모 미리보기 verso를 실제 연속 지면으로 구성해 접힌 종이 아래에서 다음·이전 내용이 보이게 한다.
- 접힘 그림자 최대 불투명도를 낮추고 내부 그림자의 채도를 제거해 무광 종이 톤으로 조정한다.
- 플립 스테이지에 layout/paint containment와 overflow clip을 적용해 호버 접힘이 문서 높이와 스크롤 폭을 변경하지 못하게 한다.
- 마지막 펼침면에서는 엔진의 페이지 모서리 미리보기를 끄고 우측 하단 입력을 차단한다.
- 첫 펼침면이 표지로 닫혀 정착하는 짧은 구간에는 본문 recto를 숨겨 오른쪽 이미지가 한 프레임 노출되지 않게 한다.
- 첫·마지막 표지는 엔진이 권장하는 `hard` density를 유지해 표지 앞면과 안쪽 면이 같은 3D 회전으로 움직이게 한다.
- 표지 닫힘을 마우스 좌표 기반 clip으로 보정하지 않고 엔진의 페이지 스택과 회전 행렬로 처리한다.
- 닫힌 표지, 첫 펼침면, 마지막 펼침면에서는 모서리 호버 미리보기를 끄고 실제 클릭·드래그 입력만 허용한다.
- 클릭 플립 애니메이션 중에는 투명 입력 가드를 두어 더블클릭의 두 번째 입력이 다음 지면을 열지 못하게 한다.
- Cover 선택과 사진/GIF 첨부 도구를 제거하고 책·메모 편집에 필요한 UI만 유지한다.
- 왼쪽 메모 목록은 8개씩 페이지를 나누고 목록 페이지 이동 시 해당 묶음의 첫 메모로 책도 이동한다.
- 플립북 페이지 수가 바뀔 때 엔진을 안전하게 다시 초기화해 연속 메모 추가 중 DOM 복제 오류를 막는다.
- 새 메모 추가로 엔진을 다시 초기화할 때 시작 지면을 새 메모로 지정해 표지부터 넘기는 연출을 만들지 않는다.
- 마지막 펼침면의 오른쪽 페이지는 편집 입력을 제외한 포인터 시작을 차단해 드래그로도 마지막 경계를 넘지 못하게 한다.
- 모든 지면에서 엔진의 모서리 호버 미리보기를 끄고 클릭 또는 누른 채 드래그할 때만 접힘 계산을 시작한다.
- 페이지 수 변경으로 엔진을 다시 만드는 동안 원본 지면 DOM과 책을 숨겨 초기 배치의 큰 지면이 한 프레임 노출되지 않게 한다.
- 메모별 recto/verso 복제를 제거하고 각 메모를 물리 지면 하나에만 배치한다.
- 첫 펼침면은 타이틀/1번 메모, 다음 펼침면은 2번/3번 메모 순서가 되도록 물리 페이지 인덱스를 연속 구성한다.
- 마지막 메모가 왼쪽 지면에 놓이는 경우에만 빈 오른쪽 지면을 보충하고 뒷표지는 별도 마지막 장으로 유지한다.
- 제목·내용 입력의 `mousedown`을 캡처 단계에서 차단해 플립 엔진의 부모 DOM 리스너가 입력 드래그를 페이지 넘김으로 해석하지 못하게 한다.
- 엔진이 마지막 펼침면 이후의 지면을 보고하면 애니메이션 없이 마지막 펼침면으로 즉시 복구한다.
- 초기 짧은 글 예시를 13개로 구성하고 목록 페이지네이션을 긴 글과 같은 이전·숫자·다음 형식으로 통일한다.
- 첨부 업로드 도구는 다시 노출하지 않고 일부 초기 짧은 글에 예시 사진을 연결해 책 지면 안에서 함께 표시한다.
- 모든 메모 첨부를 작은 1:1 프레임으로 표시하고 5번과 12번 첨부는 프로젝트 내부의 반복 애니메이션 GIF로 구성한다.
- 첨부의 작은 최대 너비 제한을 제거해 본문 아래 지면 너비를 채우는 Instagram형 대형 1:1 프레임으로 표시한다.
- 첨부 지면도 비첨부 지면과 메타·제목·본문 시작 위치를 동일하게 유지하고, 정사각형 이미지는 문서 흐름과 분리해 글 아래 남는 공간에 고정한다.
- 하단 정사각형은 데스크톱 230px·모바일 175px까지 확대하고 얇은 외곽선과 부드러운 그림자로 인쇄 사진 같은 깊이를 준다.

## Implementation Notes
- Pointer capture 기반 모서리 드래그와 진행률 기반 rotateY를 구현했다.
- 모서리 누름 즉시 종이 말림, 접힌 면, 그림자가 나타나도록 구현했다.
- 닫힌 책은 펼친 책과 동일한 정면 원근, 표지, 책등, 종이 단면을 사용한다.
- 펼친 상태에서는 양쪽을 같은 종이 재질과 동일한 폭으로 구성하고 중앙 골과 가장자리 음영으로 연결한다.
- 첫 펼침의 왼쪽은 타이틀 지면, 이후 펼침의 왼쪽은 직전 메모를 인쇄된 형태로 노출한다.
- 책 열기와 닫기는 별도 lifecycle로 관리하고, 페이지 넘김은 완만한 easing과 늘어난 정착 시간을 사용한다.
- 표지 클릭으로 책을 열고 첫 페이지 왼쪽 모서리로 닫는다.
- 연속 입력 중 중복 전환을 막고 컴포넌트 해제 시 timer를 정리한다.
- 메모 추가, 편집, 표지 선택, 이미지 첨부 기능은 유지했다.

## Result
- ESLint, TypeScript, 프로덕션 빌드 통과
- `/memo` HTTP 200 확인
- 실제 브라우저에서 닫힌 책과 펼친 책 시각 상태 확인
- 펼친 책의 좌우 페이지 폭이 동일하고 opening 종료 후 `open` 상태가 되는 것을 확인
- 실제 브라우저에서 이전 모서리가 왼쪽 지면의 하단에 속하고, 이전 전환 중 왼쪽 지면만 약 77도까지 오른쪽으로 회전하는 것을 확인
- 다음/이전 양방향 전환 중 목표 제목이 아래 지면에 먼저 렌더링되고 정착 후 제거되는 것을 확인
- 닫힌 상태와 펼친 상태가 동일한 Book DOM을 사용하고 표지가 같은 책등에서 회전하는 것을 확인
- 실제 브라우저에서 표지의 작은/중간 모서리 드래그, 부족한 드래그의 원위치 복귀, 충분한 드래그의 책 펼침을 확인
- 펼친 책에서 다음 및 이전 모서리 드래그와 마지막 지면 이후 이동 차단, 첫 펼침면에서 표지 닫기를 확인
- 모서리 호버 전후 문서 높이 `1250px`, viewport 폭 `1425px`, 스크롤 위치가 동일하게 유지되는 것을 확인
- 오른쪽 드래그로 다음 페이지, 마지막 페이지 경계, 왼쪽 드래그 복귀 및 첫 페이지 책 닫기 확인
- 마지막 펼침면 우측 하단 호버 시 내부·외부 그림자가 모두 `none`이며 드래그 후에도 물리 지면 `[3, 4]`가 유지되는 것을 확인
- 첫 펼침면을 표지로 닫을 때 정착 구간의 본문 recto가 `hidden`이고 표지 지면 `[0]`만 노출되는 것을 확인
- 표지 닫기 드래그에서 표지와 왼쪽 안쪽 면이 각각 약 `-143°/37°`, `-89°/91°`, `-36°/144°`로 대응 회전하며 홈페이지 배경을 드러내는 것을 확인
- 왼쪽 하단 모서리 클릭 전환에서도 표지와 안쪽 면이 대응 회전하고 최종 표지 지면 `[0]`만 남는 것을 확인
- 첫 펼침면 왼쪽 하단 호버 시 표지 transform과 내부·외부 그림자가 모두 `none`인 것을 확인
- 닫힌 표지는 엔진 초기화 시점부터 호버 미리보기를 끄고 잔여 접힘 그림자도 숨긴다.
- 닫힌 표지 우측 하단 호버 시 표지 transform과 내부·외부 그림자가 모두 `none`이며, 같은 위치를 클릭하면 펼침면 `[1, 2]`로 열리는 것을 확인
- 9번째 메모 추가 시 목록에 `2 page`가 활성화되고 항목 1개와 책 지면 `[17, 18]`이 표시되는 것을 확인
- `1 page` 선택 시 항목 8개와 첫 책 지면 `[1, 2]`로 돌아오는 것을 확인
- Cover 텍스트, 파일 입력, 사진/GIF 첨부 문구가 렌더링되지 않는 것을 확인
- 새 메모 추가 후 `40ms`부터 새 메모 지면 `[5, 6]`이 표시되고 표지는 계속 `display: none`인 것을 확인
- 마지막 오른쪽 페이지 중앙에서 왼쪽으로 드래그한 뒤에도 지면 `[5, 6]`과 마지막 상태가 유지되는 것을 확인
- 중간 지면의 모서리 호버 후에도 모든 지면 transform이 비어 있는 것을 확인
- 하단 스크롤 상태에서 새 메모 추가 중 초기화 전 지면 노출 `0개`, 스크롤 위치 `291px` 고정, 초기화 후 새 지면 `[7, 8]`만 표시되는 것을 확인
- 첫 펼침면 `[1, 2]`에서 1번 메모가 오른쪽에, 다음 펼침면 `[3, 4]`에서 2번 메모가 왼쪽과 3번 메모가 오른쪽에 표시되는 것을 확인
- 마지막 오른쪽 지면의 제목과 내용 입력에서 왼쪽으로 드래그한 뒤에도 지면 `[3, 4]`와 새 메모 활성 상태가 유지되는 것을 확인
- 마지막 펼침면으로 향하는 더블클릭 중 두 번째 입력이 가드에 차단되고 물리 지면 `[3, 4]`에서 멈추는 것을 확인
- 닫기 임계값에 못 미친 드래그가 원위치로 돌아오면 왼쪽 타이틀 지면이 다시 `visible`로 복원되는 것을 확인
- 별도 화살표와 책 닫기 버튼이 렌더링되지 않음을 확인
- 초기 짧은 글 13개가 구성되어 8개·5개 두 목록 페이지로 나뉘고, 하단 표시가 긴 글과 같은 `← 1 2 →` 구조인 것을 확인
- 2·5·9·12번 예시 메모에 사진과 대체 문구가 연결되고 첨부 지면용 축소 간격이 적용된 것을 확인
- 네 첨부가 모두 1:1 프레임으로 표시되고, 5·12번의 320×320 GIF가 각각 12프레임 반복 애니메이션과 `image/gif` 응답으로 제공되는 것을 확인
- 첨부 프레임이 본문 열 너비 100%를 사용하고 첨부 지면의 메타·본문 간격을 줄여 큰 정사각형이 글 아래 공간에 배치되는 것을 확인
- 첨부 유무와 관계없이 메타·제목·본문의 padding과 시작 좌표가 같고, 데스크톱 최대 230px·모바일 최대 175px 정사각형이 지면 하단 빈 공간에 외곽선과 그림자를 갖고 독립 배치되는 것을 확인
