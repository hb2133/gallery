# Reference 기반 사진 포트폴리오 구현

## Summary
- `Reference_1`의 방향형 갤러리 탐색 구조와 `Reference_2`의 Vercel식 미니멀 UI를 결합한 사진 포트폴리오를 구현한다.

## Background
- Instagram, 블로그, 개인 갤러리로 함께 사용할 수 있는 반응형 포트폴리오가 필요하다.
- 제공된 레퍼런스 외에 실제 사진 자산은 없으므로 무료 사용 가능한 Unsplash 사진을 데모 자산으로 사용한다.

## Scope
- 방향형 카테고리 탐색과 중앙 대표 작품 전환
- 반응형 작품 그리드와 카테고리 필터
- 키보드 접근이 가능한 작품 상세 오버레이
- 저널/소개/외부 소셜 진입점
- 디자인 토큰, 메타데이터, 린트 및 빌드 검증
