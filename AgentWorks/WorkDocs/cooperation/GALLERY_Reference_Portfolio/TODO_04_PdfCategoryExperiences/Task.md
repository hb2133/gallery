# Task

## Context
- `Reference/기본 화면.pdf`와 `Reference/각 카테고리 선택 시 (총 4가지).pdf`를 기준으로 기존 인터랙티브 아카이브를 확장한다.

## Current Understanding
- 기본 화면의 중앙 선택 인터랙션은 기존 구현을 유지한다.
- 선택 후 네 목적지는 사진, 영상·음악, 긴 글, 한 줄 메모다.
- 사진은 정사각형 중심 그리드와 상세 이미지 좌우 탐색이 필요하다.
- 영상·음악은 썸네일 카드형 목록, 긴 글은 블로그형 읽기 경험이 필요하다.
- 한 줄 메모는 페이지 추가, 내용 편집, 이미지 첨부, 표지 변경이 가능한 노트 형태가 적합하다.

## Decision Notes
- 로그인은 PDF에서 결정되지 않은 질문으로 표시되어 이번 구현 범위에서 제외한다.
- 각 독립 목적지는 BasePanel과 route로 분리한다.
- 사진 상세는 기존 LayeredPanel을 확장한다.

## Implementation Notes
- 메인 선택 상태의 네 외곽 박스를 사진, 영상·음악, 긴 글, 한 줄 메모 목적지로 연결했다.
- 사진 상세 LayeredPanel에 좌우 버튼과 키보드 방향키 탐색을 추가했다.
- 영상·음악은 로컬 영상과 썸네일 카드, 종류 필터, 외부 YouTube 진입점으로 구성했다.
- 긴 글은 글 목록과 선택한 본문을 한 화면에서 읽는 블로그형 레이아웃으로 구성했다.
- 한 줄 메모는 페이지 추가, 선택, 이전/다음 이동, 제목과 본문 편집, 표지 변경, 사진/GIF 첨부를 구현했다.

## Result
- `/`, `/gallery`, `/media`, `/writing`, `/memo` 정적 route가 모두 빌드됐다.
- 375px 모바일에서 모든 대상 route의 가로 넘침이 없고 이름 없는 버튼이 없음을 확인했다.
- 메인 선택 후 미디어 route 이동, 사진 상세 좌우 전환과 Escape 닫기, 메모 추가와 편집을 브라우저에서 검증했다.
- ESLint, TypeScript 검사, Next.js 프로덕션 빌드를 통과했다.
