# Task

## Context
- `Reference_3`, `Reference_4`를 기준으로 메인 히어로를 5개 박스 인터랙션으로 교체한다.

## Current Understanding
- 기본 배치는 중앙과 상하좌우의 십자형 5개 박스다.
- 바깥 4개 박스는 카테고리이며, 선택 시 중앙 박스는 고정한 채 나머지 박스가 카테고리별 형태로 이동한다.
- 선택한 단어는 중앙에 표시하고, 중앙 단어를 누르면 기본 배치로 돌아간다.

## Decision Notes
- 기존 4개 갤러리 카테고리를 바깥 박스에 대응한다.
- Architecture는 십자, Portraits는 사각 분산, Journeys는 T자, Journal은 가로 일렬 형태를 사용한다.
- 선택 상태에서는 레퍼런스처럼 다른 박스의 단어를 숨긴다.

## Implementation Notes
- 기존 이미지 중심 히어로를 중앙 고정형 5박스 인터랙션으로 교체했다.
- Architecture, Portraits, Journeys, Journal에 각각 십자, 사각 분산, T자, 가로 일렬 배치를 연결했다.
- 선택 시 바깥 단어를 숨기고 중앙 문구를 선택 단어로 교체했다.
- 중앙 단어를 누르면 `Archive` 기본 십자 배치로 복귀하도록 구현했다.
- 기본 중앙 박스의 문구를 비우고 위 A, 아래 B, 왼쪽 C, 오른쪽 D로 표기를 단순화했다.
- 모든 숫자 표기를 제거하고 hover 시 흑백 반전, 테두리, 그림자가 나타나도록 보강했다.
- A 선택도 기본 상태와 확실히 구분되도록 상단 방향 군집 형태로 이동시켰다.
- hover 효과를 색상 반전 대신 약 4.5% 확대와 가벼운 그림자로 조정했다.
- 선택 후 주변 네 박스를 disabled 처리해 중앙 알파벳만 hover 및 초기화할 수 있도록 제한했다.
- 초기 상태에서는 중앙 사각형만 유지하고 A/B/C/D는 회색 텍스트 버튼으로 표시하도록 변경했다.
- 알파벳 선택 시에만 바깥 검은 사각형이 나타나 선택 형태로 재배치되도록 상태 스타일을 분리했다.
- 초기화 시 A/B/C/D는 박스 이동이 끝날 때까지 투명도를 0으로 유지하고, 원래 위치에 도착한 뒤 fade-in하도록 지연 시간을 분리했다.
- 복귀 체감 속도를 높이기 위해 이동 시간을 680ms에서 480ms, 글자 대기를 680ms에서 460ms, fade-in을 150ms로 단축했다.
- 이동하는 박스와 A/B/C/D 글자 버튼을 별도 레이어로 분리했다.
- 복귀 시작과 동시에 글자는 원래 고정 위치에서 fade-in하고, 검은 박스만 선택 위치에서 기본 위치로 이동하도록 수정했다.
- 선택 시 글자는 뒤쪽 레이어, 검은 박스는 앞쪽 레이어에 배치해 박스가 글자를 자연스럽게 가리도록 수정했다.
- 검은 박스 이동은 지연 없이 클릭 직후 시작하는 기존 타이밍으로 복원했다.

## Result
- 중앙 박스 위치가 모든 상태에서 동일한 것을 브라우저 좌표로 확인했다.
- 데스크톱과 390px 모바일에서 상태 전환 및 가로 오버플로 없음을 확인했다.
- ESLint와 Next.js 프로덕션 빌드를 통과했다.
- A/B/C/D 모든 선택에서 바깥 박스 좌표가 변경되고 중앙 글자가 올바르게 바뀌는 것을 확인했다.
- 선택 후 주변 박스에 hover 크기 변화와 클릭 상호작용이 없고 중앙 박스만 동작하는 것을 확인했다.
- 초기 바깥 버튼 배경은 투명, 중앙 배경은 검정이며 선택 후 바깥 배경이 검정으로 전환되는 것을 확인했다.
- 복귀 100ms 시점 글자 opacity 약 0.29, 좌표는 초기 위치와 동일함을 확인했다.
- 글자 z-index 2, 검은 박스 z-index 3, 검은 박스 이동 지연 없음과 초기 글자 클릭 가능 상태를 확인했다.
