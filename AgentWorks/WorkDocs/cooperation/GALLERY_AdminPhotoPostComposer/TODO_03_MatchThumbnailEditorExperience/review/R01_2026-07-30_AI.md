Date: 2026-07-30
Result: approved

## Scope
- 새 게시글 썸네일 편집 UI와 텍스트 레이어 저장.
- 중복 이미지 URL의 공간 좌표 대응.
- 빠른 내용 이미지 드래그 안정화.
- 사진 카테고리와 시작 목적지 화면 전환.

## Findings
- 작성기 초안은 비영속 상태이며 게시 결과만 기존 서버 초기 상태 SSOT에 저장된다.
- 이미지 선택 취소는 기존 썸네일을 제거하지 않는다.
- 텍스트 레이어는 기존 정규화 함수를 공유해 최대 개수, 폰트 크기, 색상, 좌표 범위를 일관되게 제한한다.
- 중복 URL 좌표는 순번 대응을 우선해 1페이지와 20페이지의 실제 이웃 관계가 유지된다.
- 드래그 중 이전 Web Animation을 취소해 transform 중첩을 방지하며 드롭 시 마지막 포인터 슬롯을 보존한다.
- 전환 효과는 reduced-motion 환경을 존중한다.
