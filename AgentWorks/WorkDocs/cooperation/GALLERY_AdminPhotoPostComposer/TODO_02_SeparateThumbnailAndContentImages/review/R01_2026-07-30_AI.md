# R01 AI Review

## Scope
- 새 게시글 썸네일과 내용 이미지 입력 분리
- 토글형 작성 UI
- 업로드 수량 및 fallback 검증

## Findings
- 썸네일은 선택 사항이며 한 장만 입력할 수 있다.
- 내용 이미지는 UI와 Manager 양쪽에서 1~20장으로 제한된다.
- 별도 썸네일이 없으면 첫 내용 이미지가 카드 표지로 사용된다.
- 별도 썸네일은 내용 이미지 상세 목록에 섞이지 않는다.
- 이미지 영역 높이와 무관하게 게시글 기본 입력 항목은 상단에 조밀하게 정렬된다.
- 제목 없이 게시할 수 있고 빈 제목은 썸네일 텍스트 레이어를 생성하지 않는다.
- 서버 초기 상태와 브라우저 동기화가 같은 `NormalizePhotoPosts`를 사용한다.

## Decision
- Approved.
