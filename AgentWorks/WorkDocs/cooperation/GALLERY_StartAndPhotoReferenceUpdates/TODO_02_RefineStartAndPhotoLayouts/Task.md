# Task

## Context
- 시작 화면의 장르 글자 대비와 다크 테마 색상 반전을 보완한다.
- 사진 목록을 책 표지와 문구 슬롯 형태로 조정한다.
- 상세 팝업의 보기 방식 선택기와 페이지 번호 노출 조건을 수정한다.

## Current Understanding
- 다크 테마에서는 A 마크와 말풍선도 배경/전경 토큰을 따라 반전되어야 한다.
- 사진 카드는 정사각형보다 세로형 책 표지 비율이 레퍼런스에 가깝다.
- 보기 방식 선택기는 패널 바깥에 두되 현재 LayeredPanel의 상태 변경 계약을 유지한다.

## Implementation Notes
- 시작 화면 장르 글자를 전경색 22% 수준으로 옅게 조정했다.
- A 마크 글자와 각진 말풍선 배경이 테마 토큰을 따라 함께 반전되도록 했다.
- 사진 카드를 3:4 세로형 책 표지와 하단 문구 슬롯 구조로 조정했다.
- 보기 방식 선택기를 상세 패널 바깥 위쪽으로 옮기고 버튼 문구를 `1`, `2`로
  변경했다.
- 우측 페이지 바로가기는 책 보기일 때만 렌더링한다.
