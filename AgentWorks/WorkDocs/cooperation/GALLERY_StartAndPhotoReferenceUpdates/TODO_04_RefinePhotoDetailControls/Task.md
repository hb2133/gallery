# Task

## Context
- 보기 방식 선택기는 팝업 좌측 상단의 왼쪽 바깥에 위치해야 한다.
- 책 보기에서는 좌우 화살표를 제거하고 하단 페이지 수를 숫자로 표시해야 한다.

## Current Understanding
- PanelShell을 기준으로 선택기를 왼쪽 방향으로 배치하면 패널과 상태 책임을
  변경하지 않고 요구 위치를 맞출 수 있다.
- 책 보기의 페이지 바로가기는 유지하고 캐러셀 화살표와 점 인디케이터만
  보기 형식에 따라 분리한다.

## Implementation Notes
- 보기 방식 `1`, `2` 선택기를 PanelShell 좌측 상단의 바깥 영역으로 옮겼다.
- 작은 화면에서는 팝업 왼쪽 공간에 세로로 배치한다.
- 책 보기에서는 이전/다음 원형 버튼과 점 인디케이터를 렌더링하지 않는다.
- 책 보기 하단에 `현재 페이지 / 전체 페이지` 숫자를 표시한다.
- 우측 페이지 바로가기는 책 보기에서 계속 제공한다.
