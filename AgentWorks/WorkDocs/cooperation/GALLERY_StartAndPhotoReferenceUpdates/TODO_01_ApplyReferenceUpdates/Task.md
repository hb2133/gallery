# Task

## Context
- `Reference`의 시작 페이지 PDF 2개와 사진 게시판 PDF 5개를 현재 화면과
  대조해 표시 및 탐색 동작을 수정한다.

## Current Understanding
- 시작 페이지 관리 항목은 헤더/히어로 설정 데이터가 소유한다.
- 사진 게시물마다 표지, 제목 위치, 세부 분류, 기본 보기 형식과 스크롤
  방향을 지정하도록 데이터 계약을 확장한다.
- 상세 보기 전환과 현재 이미지 상태는 GalleryIndexBasePanel Controller가
  소유하고 LayeredPanel은 해당 상태를 렌더링한다.

## Observed Issues
- 기존 말풍선은 둥근 캡슐형이며 문구가 단일 고정 문자열이었다.
- 선택 타일은 검은 면만 표시하고 게시판 대표 이미지를 사용하지 않았다.
- 사진 목록은 세부 분류와 표지/제목 배치 설정이 없었다.
- 상세 패널은 가로 화살표 캐러셀만 지원했다.

## Decision Notes
- 서버 저장형 CMS가 없는 현재 범위에서는 변경 가능 콘텐츠를 정적 설정 및
  게시물 데이터에 분리하고 화면이 해당 설정을 즉시 소비하게 한다.
- 상세 뷰는 게시자가 지정한 기본 형식으로 열되, 독자도 가로/세로 스크롤과
  책 보기를 전환할 수 있게 한다.
- 기존 Panel/Section/Controller 경계를 유지한다.

## Implementation Notes
- 각진 말풍선과 복수 문구 랜덤 선택, 빈 문구 미표시를 구현했다.
- 헤더 외부 링크를 설정 배열로 분리하고 흑백 테마 전환을 추가했다.
- 장르 선택 후 이동 타일에 장르별 대표 이미지를 표시한다.
- 사진 게시물에 별도 표지, 제목 위치, 세부 분류, 보기 형식, 스크롤 방향
  필드를 추가했다.
- 세부 분류 필터와 이미지 위 제목 배치를 구현했다.
- 상세 패널에 가로/세로 스크롤, 책 펼침 보기, 형식 전환, 키보드 방향키,
  점 인디케이터와 페이지 바로가기를 구현했다.
