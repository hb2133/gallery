# Task

## Context
- 보기 방식 변경 안내, 책 형태 아이콘, 목차 모션, 실제 폰트와 GIF 배경 팔레트가 빠져 있었다.
- 카드 외곽선도 반복 패턴이어서 글마다 다른 종이 느낌이 나지 않았다.

## Current Understanding
- 보기 전환과 패널 진입은 CSS 애니메이션으로 처리하고, 카드 외곽선은 글 ID 기반 결정적 난수로 생성해야 SSR과 hydration이 일치한다.

## Observed Issues
- 런타임에서 확인된 현상이나 새로 발견된 문제를 적는다.

## Decision Notes
- 방향이 바뀐 이유와 폐기한 가설을 적는다.

## Initial Render Harness
- 글꼴과 배경은 기존 보기 설정 쿠키를 서버 첫 HTML에서 읽는다.
- 카드 외곽선은 글 ID만 사용해 서버/클라이언트가 같은 polygon을 만든다.

## Implementation Notes
- 단면/양면/스크롤을 책 지면 SVG 아이콘으로 교체하고 중앙 전환 안내를 추가했다.
- 목차와 설정 패널에 좌우 슬라이드 진입 모션을 적용했다.
- Noto Sans KR, Noto Serif KR, Gowun Dodum, Nanum Gothic Coding을 실제 본문과 선택 버튼에 연결했다.
- GIF 기준 10개 배경 팔레트를 추가하고 설정 저장 정규화 범위를 확장했다.
- 단면/스크롤 본문 폭과 장 제목 중앙 배치를 레퍼런스에 맞췄다.
- 카테고리를 좌측, 검색과 글쓰기를 우측에 배치했다.
- 새 글 ID마다 서로 다른 불규칙 종이 외곽선을 결정적으로 생성한다.

## Result
- 카드 7개 모두 고유 외곽선, 목차 6행 슬라이드, 중앙 전환 안내, 실제 네 글꼴, 배경 10종을 브라우저에서 확인했다.
- 관리자 화면에서 카테고리 x=120, 검색 x=1067, 글쓰기 x=1259 순서를 확인했다.
- 브라우저 오류 없이 타입 검사와 ESLint를 통과했다.
