# 메인 페이지 히어로 전용 구성

## Summary
- 메인 페이지를 헤더와 인터랙티브 히어로만 표시하도록 단순화한다.

## Background
- 사용자가 메인 페이지에서 휠을 내렸을 때 이어지는 콘텐츠가 필요 없다고 요청했다.

## Scope
- 메인 패널의 갤러리, 저널, 푸터 렌더링 제거
- 제거된 섹션을 가리키는 헤더 앵커 링크 제거
- 히어로 전용 컨트롤러 상태로 정리
