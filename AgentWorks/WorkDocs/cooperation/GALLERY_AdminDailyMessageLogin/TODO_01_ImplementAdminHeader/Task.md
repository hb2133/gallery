# Task

## Context
- 헤더의 `Archive` 문구를 관리자가 이용자에게 전하는 하루 문구로 바꾼다.
- A 박스를 Ctrl+클릭하면 관리자 로그인 창이 나타나야 한다.

## Current Understanding
- 메인, 사진, 영상·음악, 긴 글, 짧은 글, 커뮤니티 화면에 유사한 헤더 브랜드 구현이 반복된다.
- 하루 문구와 로그인 진입 동작은 화면별 구현 대신 공통 클라이언트 컴포넌트가 소유하는 것이 적절하다.

## Observed Issues
- 기존 A와 Archive 전체가 하나의 홈 링크여서 수정자 키 기반 동작을 별도로 처리하지 않았다.

## Decision Notes
- 일반 클릭은 기존 홈 또는 페이지 상단 이동을 유지한다.
- Ctrl+클릭만 기본 링크 이동을 취소하고 로그인 모달을 연다.
- 로그인 창은 관리자 전용 문구 없이 일반 계정 로그인 UI로 표시하며, 실제 인증은 요구된 예시 범위 밖이므로 제출 시 미연결 안내를 표시한다.
- Escape, 바깥 영역, 닫기 버튼으로 모달을 닫을 수 있게 한다.
- 로그인 배경에는 블러를 사용하지 않고, 하루 문구는 A 박스와 이어지는 말풍선으로 표시한다.

## Implementation Notes
- 공통 `AdminBrand` 컴포넌트와 전용 스타일을 추가했다.
- 예시 하루 문구와 로그인 UI 문자열을 중앙 문자열 모듈에 추가했다.
- 여섯 화면의 기존 Archive 브랜드를 공통 컴포넌트로 교체했다.
- 로그인 모달을 `document.body` 포털로 렌더링하고 바깥 배경의 직접 클릭에서 닫히게 했다.

## Result
- ESLint는 오류 없이 통과했으며 기존 이미지 상세 패널의 Hook 의존성 경고 1건만 확인했다.
- TypeScript 검사와 프로덕션 빌드가 통과했다.
- `/`, `/gallery`, `/media`, `/writing`, `/memo`, `/community`가 모두 HTTP 200을 반환하고 예시 하루 문구를 포함하는 것을 확인했다.
- 일반 A 클릭은 기존 링크를 유지하고 Ctrl+클릭과 Ctrl+Enter에서만 로그인 모달을 여는 이벤트 경계를 구현했다.
- 모달 배경의 블러를 제거하고 배경 직접 클릭, Escape, 닫기 버튼으로 닫히는 구조를 확인했다.
- 하루 문구를 외곽선과 꼬리가 있는 말풍선 형태로 표시하고 텍스트가 길어질 때 내부에서 말줄임 처리되게 했다.
