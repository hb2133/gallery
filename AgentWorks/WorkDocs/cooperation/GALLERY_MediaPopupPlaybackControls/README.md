# 영상 팝업 재생 컨트롤

## Summary
- 영상 상세 팝업에 재생 상태, 탐색, 음량, 속도, 전체화면 컨트롤과 작성 월 표시를 추가했다.

## Background
- 업로드 영상과 YouTube iframe이 같은 팝업 UI를 사용한다.

## Scope
- 팝업 플레이어 컨트롤과 YouTube Player API 메시지 동기화.
