# Task

## Context
- 설정창에서 같은 목적의 닫기 액션이 상단과 하단에 중복 노출됐다.

## Current Understanding
- 상단 `Close ×`를 대표적인 명시적 닫기 액션으로 유지한다.
- ESC와 배경 클릭 dismiss도 기존대로 유지한다.
- 편집창 하단은 주요 액션인 `변경사항 저장`만 남긴다.

## Observed Issues
- 설정 목록 하단의 `닫기`가 상단 `Close ×`와 기능이 같았다.
- 카테고리와 한마디 편집창의 `취소`도 상단 닫기와 기능이 같았다.
- 모바일 푸터는 두 버튼 전용 2열 레이아웃이었다.

## Decision Notes
- 사용자가 둘 중 하나만 필요하다고 요청해 상단 닫기를 유지하고 하단 중복 버튼을 제거했다.
- 편집창의 `설정 목록` 이동은 닫기와 목적이 다르므로 유지했다.

## Fix Notes
- 설정 목록의 하단 닫기 버튼과 전용 문자열·스타일을 제거했다.
- 카테고리 및 한마디 편집창의 하단 취소 버튼을 제거했다.
- 모바일에서 단일 저장 버튼을 우측 정렬하도록 변경했다.

## Result
- ESLint, TypeScript 검사, Next.js 프로덕션 빌드가 모두 통과했다.
- 상단 닫기, ESC, 배경 클릭 닫기 경로는 유지된다.
