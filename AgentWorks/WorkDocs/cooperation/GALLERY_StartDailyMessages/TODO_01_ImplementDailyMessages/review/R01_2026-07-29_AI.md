## Findings
- `daily_messages`는 JSON 배열 constraint를 가진다.
- 공개 사용자는 목록을 읽을 수 있고 관리자만 수정할 수 있다.
- 문장 편집창은 0개 이상의 항목을 추가·삭제·수정할 수 있다.
- 새 문장을 추가하면 새 입력칸으로 focus가 이동한다.
- 페이지 진입 시 현재 목록 길이를 기준으로 무작위 문장이 선택된다.
- 목록이 비어 있으면 말풍선 DOM을 렌더링하지 않는다.
- 설정 load 전에도 말풍선을 숨겨 빈 목록의 초기 flash를 방지한다.
- ESLint 경고 0, TypeScript 검사와 Next.js 프로덕션 빌드가 통과했다.

## Decision
- 요청 범위를 충족하며 커밋 가능한 상태다.
