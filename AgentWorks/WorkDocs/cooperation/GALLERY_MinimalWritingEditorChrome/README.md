# Minimal Writing Editor Chrome

## Summary
- 긴글 편집기의 고정 서식 위젯과 입력 아웃라인을 제거하고 제목·요약 줄바꿈을 읽기 화면과 맞춘다.

## Background
- 슬래시·선택 메뉴 도입 후 상단 고정 도구 모음이 중복되었다.
- 제목이 한 줄 input이라 긴 제목이 저장 화면과 다르게 가로로 넘쳤다.

## Scope
- 상단 실행 취소·서식·목록·삽입 위젯 숨김
- 입력 focus 사각형 outline 제거
- 제목·요약 자동 높이 줄바꿈
