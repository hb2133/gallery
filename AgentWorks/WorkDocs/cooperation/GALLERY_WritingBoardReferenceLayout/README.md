# 글 게시판 레퍼런스 기반 긴 글 페이지

## Summary
- `Reference/글 게시판.pdf`를 기준으로 긴 글 페이지를 목록·본문·보기 설정 3열 독서 화면으로 재구성한다.

## Background
- 기존 긴 글 페이지는 큰 소개 영역과 2열 아카이브 구조로 레퍼런스의 집중형 독서 화면과 차이가 컸다.

## Scope
- 접이식 검색·카테고리·글 목록 사이드바
- 중앙 긴 글 독서 화면
- 글꼴·글자 크기·배경색·정렬 보기 설정
- 기존 검색·필터·페이지 탐색 유지
- 데스크톱 및 모바일 반응형 배치
