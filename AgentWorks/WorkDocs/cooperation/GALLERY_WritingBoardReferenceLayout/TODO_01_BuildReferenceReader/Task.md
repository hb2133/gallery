# Task

## Context
- 글 게시판 PDF의 방문자 긴 글 화면을 현재 Writing 패널에 반영한다.

## Current Understanding
- 기존 Controller의 글 선택·검색·필터·페이지 상태와 테스트 콘텐츠는 재사용할 수 있다.
- 레퍼런스의 핵심은 왼쪽 탐색, 중앙 독서 본문, 오른쪽 보기 설정의 화면 구조다.

## Observed Issues
- 큰 소개 영역 때문에 실제 글 목록과 본문이 첫 화면 아래로 밀렸다.
- 본문 읽기 환경을 사용자가 조정할 수 없었다.
- 글 목록을 접어 본문 폭을 확보하는 기능이 없었다.

## Decision Notes
- 큰 소개 영역을 제거하고 헤더 아래 전체 높이를 3열 독서 화면으로 사용한다.
- 보기 설정은 서버 저장 없이 현재 패널 세션의 Controller 상태로 관리한다.
- 관리자 영구 저장 편집기는 별도 글 저장 모델과 권한 계약이 필요한 후속 범위로 남긴다.

## Initial Render Harness
- 저장 기능을 추가하지 않으며 기존 정적 글 배열이 SSOT다.
- 보기 설정은 기본값으로 서버·클라이언트 첫 렌더가 동일하게 시작한다.

## Fix Notes
- Writing Controller에 목록 접기와 독서 보기 설정 상태·액션을 추가했다.
- Section을 목록, Reader, 보기 설정 패널로 재구성했다.
- 글꼴 5종, 15~22px 글자 크기, 흰색·종이색·검은색 배경, 왼쪽·양쪽 정렬을 구현했다.
- 데스크톱 3열, 중간 화면 설정 팝오버, 모바일 세로 배치를 적용했다.
- 목록을 접으면 좌우 30px 여백이 대칭이 되며 보기 설정은 본문 오른쪽 위 팝오버로 표시된다.
- 헤더의 시작 화면 링크 문구를 `Back`으로 변경했다.

## Result
- 전체 ESLint, TypeScript, diff 검사와 `/writing` HTTP 200을 확인했다.
