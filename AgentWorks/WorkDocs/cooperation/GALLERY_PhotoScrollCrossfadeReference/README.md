# 사진 상하좌우 보기 교차 페이드 전환

## Summary
- Gallery 사진 상세의 상하좌우 보기 전환을 참고 GIF처럼 겹치는 교차 페이드로 변경한다.
- 방향별 3D 흔들림과 책 넘김의 0부터 시작하는 페이지 표기를 함께 적용한다.
- 참고 GIF의 흰색 꺾쇠 화살표와 중단 가능한 연속 페이지 전환을 적용한다.

## Background
- 기존 구현은 현재·다음 이미지를 이동 방향으로 100% 슬라이드했다.
- `01 사진 스크롤.gif`는 두 이미지가 같은 프레임에서 겹쳐지며 비율에 관계없이 투명도로 전환된다.

## Scope
- 버튼·키보드·드래그로 실행되는 상하좌우 보기 이미지 전환
- 책 넘김 사진 하단 페이지 표기
- 전환 중 버튼·키보드 연속 입력
- 모션 감소 설정 유지
