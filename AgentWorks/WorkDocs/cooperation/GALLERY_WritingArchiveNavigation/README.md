# 긴 글 아카이브 검색 필터 페이지 탐색

## Summary
- 긴 글이 늘어나도 쉽게 탐색할 수 있도록 검색, 카테고리 필터, 페이지 탐색을 추가한다.

## Background
- 기존 세로 목록은 글이 약 50개로 늘어나면 탐색 거리와 현재 위치 파악이 어려워진다.

## Scope
- 한 페이지 8개 목록
- 제목 및 요약 검색
- 카테고리 필터
- 이전, 페이지 번호, 다음 탐색
- 데스크톱 고정 목록 패널과 모바일 세로 목록
