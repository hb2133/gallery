# Task

## Context
- 긴 글 목록이 약 50개로 늘어났을 때 과도한 세로 스크롤 없이 글을 찾을 수 있어야 한다.

## Current Understanding
- 기존 목록은 전체 글을 한 번에 렌더링하고 별도 탐색 수단이 없었다.
- 아카이브 문맥에는 무한 스크롤보다 검색, 필터, 명시적 페이지가 적합하다.

## Observed Issues
- 모바일 목록이 가로 스크롤 방식이라 글이 많아지면 전체 위치를 파악하기 어렵다.

## Decision Notes
- 페이지당 8개를 표시한다.
- 검색이나 카테고리 변경 시 첫 페이지와 첫 결과를 선택한다.
- 데스크톱 목록 패널은 본문 스크롤 중에도 고정하고 내부 목록만 스크롤한다.
- 모바일에서는 가로 목록을 제거하고 세로 목록을 사용한다.

## Implementation Notes
- Controller에 검색, 카테고리, 페이지 상태와 필터링을 추가했다.
- Section에 검색 입력, 카테고리 선택, 결과 수, 페이지 버튼을 추가했다.
- 목록 패널의 고정 및 반응형 스타일을 구현했다.

## Result
- ESLint, TypeScript, 프로덕션 빌드 통과
- `/writing` HTTP 200 확인
- 검색, 카테고리, 페이지 탐색 UI 렌더 확인
