# Task

## Bug Context
- 상위 컨트롤러에서 상하좌우 보기의 활성 이미지를 1페이지로 초기화해도, 전환 직후 책 컴포넌트의 마지막 `onFlip` 이벤트가 이전 페이지를 다시 선택할 수 있다.

## Decision Notes
- 보기 전환 버튼을 누르는 즉시 로컬 보기 모드 참조를 갱신한다.
- 상하좌우 보기로 전환을 시작한 뒤 도착하는 책 넘김 이벤트는 무시한다.

## Fix Notes
- 보기 모드 변경을 로컬 함수로 통합했다.
- 늦게 도착한 `onFlip` 및 책 애니메이션 상태 이벤트가 상하좌우 보기 상태를 덮어쓰지 않도록 차단했다.

## Result
- 상하좌우 보기 전환 직후 책 컴포넌트에서 늦게 도착하는 페이지 이벤트가 이전 페이지를 다시 선택하지 않는다.
- 상위 컨트롤러의 1페이지 초기화와 함께 적용되어 상하좌우 보기는 항상 첫 이미지에서 시작한다.
- TypeScript, 관련 ESLint, 대상 파일 diff check를 통과했고 개발 서버에서 `/gallery` 응답 200을 확인했다.
