# 사진 상세 닫기 및 페이지 표시 정리

## Summary
- 사진 상세 팝업 닫기 버튼과 책 보기의 사진별 페이지 표시를 단순화했다.

## Background
- Close 텍스트와 중복된 개별 페이지 번호 및 하단 페이지 표시가 화면을 복잡하게 만들었다.

## Scope
- 우측 상단 닫기 버튼을 `×` 아이콘으로 변경.
- 책 페이지별 번호와 개별 페이지 버튼 제거.
- 기존 페이지 버튼 위치에 현재/전체 표시 배치.
