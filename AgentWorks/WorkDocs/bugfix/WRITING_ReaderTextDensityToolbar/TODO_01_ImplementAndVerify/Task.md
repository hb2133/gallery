# Task

## Bug Context
- Writing 게시글 제목과 내용 사이가 넓고 본문 한 페이지에 보이는 줄 수가 적다.
- 전체화면 버튼 왼쪽의 보기 방식 버튼이 외부 1·2 전환과 중복된다.

## Current Understanding
- 제목 여백 규칙이 두 번 선언돼 큰 값이 덮어썼다.
- 기본 읽기 설정이 18px, 1.85 행간, 24px 문단 간격, 48px 상하 여백이다.

## Observed Issues
- 과거 기본값을 쿠키에 저장한 사용자는 기본값 상수만 변경하면 이전 밀도가 계속 적용된다.

## Decision Notes
- 사용자 커스텀 설정은 유지하고 정확히 과거 기본 밀도인 쿠키만 새 기본값으로 변환한다.
- 팝업 외부 1·2 보기 전환은 유지하고 내부 중복 메뉴와 전용 연출만 삭제한다.

## Initial Render Harness
- 서버 첫 HTML에서 사용하는 읽기 설정 정규화 단계에 과거 기본 밀도 변환을 추가해 hydration 전후 값을 동일하게 유지한다.

## Fix Notes
- 제목 크기를 본문의 1.4배, 제목 아래 여백을 `.85em`으로 조정했다.
- 기본값을 16px, 1.6 행간, 14px 문단 간격, 40px 상하 여백으로 변경했다.
- 내부 보기 메뉴 state, 아이콘, 메뉴, 안내 연출과 CSS를 삭제했다.

## Result
- 과거 기본값 변환 테스트, 관련 ESLint, TypeScript와 diff 검사가 통과했다.
