# Task

## Bug Context
- 사진 게시글 1번 책 보기 오른쪽의 페이지 바로가기가 토글 방식이라 많은 페이지를 연속해서 탐색하기 불편하다.

## Current Understanding
- `BookPageIndex`에는 이미 세로 스크롤과 현재 페이지 자동 정렬이 구현되어 있다.
- 토글 상태와 숨김 스타일만 제거하면 새 탐색 컴포넌트나 의존성 없이 요구사항을 충족한다.

## Observed Issues
- 목록이 닫힐 때 모든 페이지 버튼이 키보드 탐색에서도 제외된다.
- 페이지를 선택할 때마다 목록이 다시 닫힌다.

## Decision Notes
- 1번 스타일에서 페이지 목록을 오른쪽에 항상 노출한다.
- 데스크톱과 모바일 모두 고정 최대 높이 안에서 세로 스크롤하게 한다.
- 현재 펼침면 자동 중앙 정렬 로직은 그대로 재사용한다.

## Initial Render Harness
- 저장값이나 서버 초기 상태를 변경하지 않는 순수 표시 방식 수정이므로 해당 없음.

## Fix Notes
- 페이지 바로가기 토글과 `IsPageIndexOpen` 상태를 제거했다.
- 페이지 인덱스를 상시 렌더링하고 모든 번호 버튼을 즉시 선택 가능하게 했다.
- 오른쪽 인덱스 영역의 높이를 제한하고 기존 `overflow-y: auto`를 유지했다.

## Result
- TypeScript, 대상 ESLint, diff 검사 및 Next.js 프로덕션 빌드를 통과했다.
